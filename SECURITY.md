# Security

PConDistance is intended for your own devices on a trusted LAN. It is not hardened for exposure to the Internet. HTTP/video/file streams do not provide transport encryption. Authenticated discovery does not make other traffic encrypted.

Never forward the listener port on your router. Use a trusted network or an authenticated encrypted tunnel. Keep access keys private and rotate them if disclosed. Android screen capture and Accessibility control require explicit device-owner consent.

Please do not post working credentials, private files, personal device addresses or a weaponized exploit in public issues. Use GitHub's private vulnerability reporting if the repository offers it. If private reporting is unavailable, open a minimal issue requesting a private reporting channel without publishing technical exploit details or secrets.

Сообщай об уязвимостях без ключей, личных файлов и чужих данных. Для чувствительных подробностей используй приватное сообщение об уязвимости, если оно доступно в GitHub; иначе попроси приватный канал через короткий Issue без эксплуатации и секретов.
